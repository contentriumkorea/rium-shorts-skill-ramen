# 편집자가 고를 수 있는 초벌 기준

## 시작 대화

사용자가 “사람 많고 재밌는 느낌”만 말해도 먼저 자료를 본다. 편집 용어부터 묻지 않는다. 실제 장면 2~3개를 근거로 아래처럼 제안한다.

> 줄 서 있는 전경과 면을 들어 올리는 장면이 좋습니다. ① ‘이 줄 끝에는 뭐가 있을까?’로 시작해 라면을 보여주는 방문기, ② ‘오늘 구미역 앞 풍경’ 제목을 짧게 두고 사람·음식·반응을 빠르게 보여주는 현장 스케치가 가능합니다. 저는 ①을 추천합니다. 어떤 쪽으로 갈까요?

예문의 인파/줄/장면은 실제 확인했을 때만 사용한다. 방향만 묻고 위치·폰트·BPM 수치를 초보 편집자에게 결정하게 떠넘기지 않는다. 사용자가 이미 준 조건은 제안에 반영한다. 대본 확정과 방향 선택을 불필요한 두 번의 승인으로 쪼개지 않는다.

## 대본과 장면으로 길이 정하기

30초를 본편 기본값으로 잡지 않는다. **대본이 있으면 제공된 원문이 우선**이다. 정상 속도로 읽는 실제 발화, 문장 사이 호흡, 행동·반응을 이해하는 데 필요한 장면을 기준으로 길이를 정한다. 기존 녹음이나 실제 낭독 확인값이 없으면 예상 길이라고 표시하고, 확정 음원이 생기면 타임라인과 다시 대조한다. 글자 수 계산을 실제 낭독 측정으로 보고하거나 길이 확인만을 위해 요청하지 않은 음성 생성을 시작하지 않는다.

내레이션과 동시에 보여주는 B-roll은 같은 타임라인 구간이다. 음성 길이에 그 화면 길이를 다시 더하지 않는다. 발화 사이 현장음·반응이나 말이 끝난 뒤 행동을 보여줄 시간이 필요할 때만 별도 구간으로 배치한다.

**대본이 없으면 45~90초 중 적절한 길이를 추천**한다. 전달할 정보, 확인된 좋은 장면, 행동의 시작과 결과, 자막을 읽는 시간을 보고 선택하며 모든 편을 45초·60초·90초 중 하나로 고정하지 않는다. 예상 길이와 그 길이가 맞는 장면 근거를 방향 제안에 함께 적는다. 유효한 소스가 부족하면 반복 화면이나 긴 정지 화면으로 채우지 말고 부족한 내용과 구성 대안을 알린다.

원문 대본의 자연스러운 길이가 45~90초 밖이면 그 길이와 이유를 밝히고, 원문을 유지하는 안과 의미를 보존한 축약·여러 편 분할안을 제시한다. 이미 위임받은 대본 수정 범위는 활용하되 범위를 넘는 원문 변경을 임의 확정하지 않는다. 목표 숫자에 맞추려고 말을 중간에 끊거나 배속하지 않고, 같은 장면·문장을 반복하거나 무의미한 여백으로 시간을 늘리지 않는다. 예상 길이, 실제 확정 길이와 차이의 이유는 [편별 관리](episode-management.md)에 남긴다.

## 훅 → 증거 → 전개 → 끝맺음

- 0~2초: 핵심 의미가 한 번에 읽히는 훅. 가능하면 첫 프레임부터, 애니메이션을 쓰더라도 2초 전에 완성. 짧은 현장 장면이 먼저 주의를 끌 수 있으나 훅 자막/발화가 뒤로 밀리면 안 된다.
- 다음 장면: 훅을 증명하는 구체적 화면. “사람 많다”면 실제 넓은 전경, “직접 만든다”면 손과 조리 과정. 음식만 보여주며 인파를 주장하지 않는다.
- 중간: 새로운 정보·행동·반응이 한 단계씩 추가된다. ‘와, 대박, 최고’만 연달아 반복하지 않는다. 보기만 하는 전경→손/면/김의 디테일→먹는 반응처럼 거리와 동작을 바꾼다.
- 끝: 먹어 본 반응, 마지막 한 가지 팁, 여운 또는 실제 연결 가능한 루프. 모든 편에 로고판·구독 CTA를 자동 붙이지 않는다.

첫 2초의 훅 이후에는 증거·전개·마무리 시간을 대본과 장면에 배분한다. 짧은 구성표를 총 길이에 비례 확대하거나 고정 비율로 끼워 맞추지 않는다. 제공된 대본을 유지하면서 첫 2초에 의미를 보여줄 필요가 있으면 원문과 맞는 짧은 화면 문구·장면을 활용한다. 인터뷰/웃음/먹는 반응은 의미가 끝나기 전에 박자 때문에 자르지 않는다.

## 내용에 따른 구성 선택

| 소스/의도 | 추천 구성 | 대안/주의 |
|---|---|---|
| 인파·현장 분위기 | 강한 첫 전경 + 현장 반응 + 음식 디테일 | 위에서 본 압축된 원근을 실제 관객 수처럼 말하지 않기 |
| 방문 동선·즐기는 방법 | 짧은 훅 → 입장/탐색 → 체험/음식 → 후기 | 단계별 문구, 필요 시 장소 라벨. 시간 순서를 바꾸면 실제 동선이라고 오인시키지 않기 |
| 여러 정보/포인트 소개 | 상단 주제 + 번호/짧은 사례 전개 | 주제가 전편을 관통할 때만 고정. 새 정보 없이 같은 제목만 오래 남기지 않기 |
| 면·먹방·조리의 쾌감 | 중앙/하중앙 짧은 문구 + 손·면·표정 우선 | 현장음 여백. 글이 음식과 입을 가리면 옮기거나 빼기 |
| 제품·우리밀 라면 소개 | 발견/질문 → 실물·조리·특징 → 반응 | 출시일/가격/원료/한정판매 등은 공식 자료 또는 확인된 소스 필요 |
| 인터뷰 | 질문을 첫 2초에 압축, 답변을 화면 증거와 연결 | 발언 의미를 바꾸는 절단·합성 금지. 긴 질문 전체를 먼저 재생할 필요 없음 |

## 문장 다루기

레퍼런스 문장을 복제하는 대신 기능을 가져온다. ‘이 줄, 어디까지 이어질까요?’(궁금증), ‘라면 먹으러 왔다가 여기서 멈췄습니다’(경험), ‘오늘 먼저 볼 세 장면’(정리)는 새 초안의 예다. 주장과 장면이 맞지 않으면 쓰지 않는다. ‘전국 1위’, ‘역대급 인파’, ‘무조건’, ‘숨겨진 맛집’은 근거 없이 만들지 않는다.

한 자막에 한 생각. 짧은 구어체와 구체적 명사를 쓴다. 앞 문장이 던진 질문에 다음 1~2장면이 답하도록 쓴다. 같은 종결형·감탄사·명사 나열을 반복하지 않는다. 긴 자막은 작게 줄이기 전에 문장을 나눈다. 한국어 문장을 휴대폰 크기로 실제 읽어 속도를 검수한다. 첫 초벌의 1~2줄·12~22자 정도는 출발점일 뿐 제한 규격이 아니다.

## 자막과 화면

촬영본을 분석해 중앙·하중앙·상단 고정 타이틀 등을 **조합해서** 제안하고 초벌 결과를 보고 재평가한다. [자막 조합·재검수](caption-layout-review.md)의 절차로 얼굴·음식·손·간판·상황을 가리는 구간을 찾아 위치 이동/문장 축약/타이틀 해제 등의 대안을 제시한다. 처음 정한 배치를 끝까지 유지하는 것을 완성 기준으로 삼지 않는다.

상단 주제 고정형은 ‘영상 전체가 하나의 질문에 답하는가’를 먼저 본다. 짧은 첫 훅만 상단에 두는 방식과 구별한다. 중앙 중심형은 얼굴·면·손의 움직임과 충돌하면 하중앙/빈 공간으로 조정한다. 자막을 피하려고 핵심 피사체를 잘라내지 않는다.

설치된 라이선스 확인 가능한 한국어 폰트를 제안하고 한 편의 기본 서체와 강조 방식부터 정한다. 특정 폰트·색·좌표를 전 편 공통 의무로 만들지 않는다. 흰 글자+외곽선·그림자는 읽히는 본문의 한 선택지이며 모든 제목과 포인트를 같은 흰 자막으로 끝내지 않는다. 불꽃이 붙은 굵은 문구, 검정 블록+강한 제목색, 분홍 제목+작은 아이콘처럼 **본문과 강조의 위계**를 장면과 톤에 맞게 계획한다. 기계적인 한 글자씩 튀는 애니메이션과 모든 컷의 줌을 기본으로 삼지 않는다.

## 포인트 그래픽을 넣을 순간

소스에서 가장 뜨거운 조리 순간, 예상 밖 발견, 한 입 뒤의 만족 반응처럼 시선을 모을 이유가 있는 구간을 찾고 [포인트 그래픽](point-graphics.md)의 실제 에셋이나 필요한 생성 이미지를 검토한다. 장면·문구·효과가 같은 의미를 말해야 한다. 예를 들어 실제 매운맛 반응이나 열기 있는 조리 컷에는 불꽃 타이포, 제품을 처음 보여주는 순간에는 반짝임, 실제 놀람에는 임팩트·번개, 만족한 표정에는 하트가 후보가 될 수 있다. 실제로 보지 않은 반응을 효과로 만들어 사실처럼 표현하지 않는다.

초벌 제안에는 적합한 순간이 있으면 `어느 컷의 어느 문구에 어떤 효과를 얼마나 보여줄지`와 추천 이유를 함께 넣는다. 이미 스타일·편집을 위임받았다면 그 범위에서 시안에 적용하고 실제 결과를 보여준다. 담백한 현장음 편처럼 강조가 흐름을 해치면 사용하지 않는 이유를 적는다. 소스 검토 없이 모든 편에 같은 스티커를 넣거나 장식이 없다는 이유만으로 다시 꾸미지 않는다.

강한 효과는 핵심 훅·반전·반응의 짧은 구간에서 힘을 쓰게 하고 본문에서는 약하게 하거나 뺀다. 2초 루프 에셋이 있다고 모든 포인트를 2초씩 보여주거나 전편 내내 반복하지 않는다. 첫 훅에 효과를 쓸 때도 문장의 핵심 의미는 2초 이내 읽혀야 한다. 한국어 문구와 장식은 가능한 별도로 보존해 문장·위치·길이를 다시 바꾸기 쉽게 한다.

## 빠른 1차 편집의 완료 기준

본편 구조와 길이 결정 근거, 소스 선택, 훅과 화면 문구, 포인트 그래픽의 선택·적용·생략 근거, 들리는 음성, 임시·확정 BGM 상태와 선택한 편집기의 편별 프로젝트·시퀀스 재수정 경로가 갖춰진 상태다. 원문 발화·호흡·행동이 끊기지 않고 확정 길이와 구간표가 맞는지 확인한다. 실제 편집 도구에서 열어 수정할 수 있는지 [편집기 실행](editor-workflow.md)에 따라 확인한다. 색보정과 미세 모션은 다음 단계일 수 있다. 미수급 음악·미생성 에셋을 이미 넣었다고 하거나 자막 초안만으로 편집 완료라고 하지 않는다. 가장 좋은 장면이 빠진 이유도 짧게 기록한다.
