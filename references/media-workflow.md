# 날짜·시간·장소와 쓸 만한 구간

## 반입과 분류

지정 폴더를 재귀 조회하되 외부 링크를 따라 다른 드라이브까지 탐색하지 않는다. 원본을 이름 변경·이동하지 않고 먼저 인덱스로 분류한다. 사용자에게 파일 정리까지 위임받은 범위에서는 검증된 복사/이동을 실행한다. 이미 Kino에 연결된 미디어는 원본 경로를 바꾸지 말고 bin/태그/인덱스를 먼저 이용한다. 대량 반입이 네트워크 업로드를 동반하면 현행 도구 안내와 승인 범위를 확인한다.

`python <skill>/scripts/inventory_media.py --source <촬영본 폴더> --output <기존 기록 폴더>/media-index.json --timezone Asia/Seoul`

이 명령은 원본을 수정하지 않는다. ffprobe가 필요하다. `--hash`는 SHA-256을 계산해 동일 바이트를 표시하며 대용량 전체에서는 시간이 든다. `--metadata-map corrections.json`으로 사용자 확인 촬영시각·장소를 보완할 수 있다. JSON 예: `{"cameraA/C001.mp4":{"shot_at":"2026-11-06T12:30:00+09:00","location":"구미역 앞","evidence":"촬영자 확인"}}`. 출력 파일이 있으면 덮어쓰지 않고 새 작업 기록 이름을 쓴다.

- 촬영시각 우선순위: 사용자/검증된 촬영 로그 → 신뢰 가능한 카메라/컨테이너 creation_time(UTC 변환 근거 기록) → 추정 후보. 태그들끼리 충돌하면 확정 금지. timezone 없는 시각은 현지 시각으로 단정하지 않는다. 파일 수정·복사 시각은 별도 보조 정보다.
- 먼저 파일의 출처를 카메라 원본/프록시/다운로드 레퍼런스/렌더 결과/생성 자산으로 구분한다. 다운로드·재인코딩·렌더 파일의 creation_time은 변환/저장 시각일 수 있다. 스크립트의 날짜 묶음은 메타데이터 후보일 뿐이며, 원본 근거 없이 ‘금요일 촬영분’으로 확정하거나 본편에 넣지 않는다. 이번 8편 레퍼런스는 스타일 근거이지 2026 구미 현장 촬영본이 아니다.
- 장소: GPS/촬영 로그/간판·부스명/현장 안내도 대조. 시각만으로 장소를 자동 확정하지 않는다. 장소가 여러 개인 파일은 **구간별** 라벨. 확인 불가는 `장소 미확인`으로 남기고 확신 낮은 결과만 묶어서 질문한다.
- 날짜·시간·장소는 인덱스로 먼저 묶는다. 실제 보관 분류가 필요할 때 `날짜/장소/카메라`를 제안한다. 영상 하나가 여러 편에 쓰여도 원본은 하나, 사용 구간만 여러 연결로 기록한다.
- Kino MEDIA bin은 파일 단위이며 한 파일은 한 bin에 속한다. 장소별 구간/에피소드별 사용 관계를 bin만으로 표현하거나 중복 임포트하지 않는다.

## 빠르게 분석하되 좋은 순간을 놓치지 않기

긴 파일은 프록시/샘플 프레임으로 1차 훑기 → 장면 전환과 음성/웃음/움직임 단서 주변 정밀 확인 → 최종 후보 in/out을 앞뒤 여유까지 보는 순서. 전체 길이에 듬성듬성 찍은 프레임만으로 ‘최고의 순간’을 확정하지 않는다. 분석된 범위와 아직 안 본 범위를 기록한다.

Kino readVideo/semantic search 결과는 후보 탐색용이다. 시각 주장은 lookAtFrames 또는 로컬 추출 프레임으로 확인하고 음성 주장은 전사와 청취로 확인한다. 처리 중인 Kino 분석을 다른 검색으로 완료된 것처럼 대체하지 않는다. 미디어 분석이 끝난 항목으로 편집 준비를 진행한다.

각 선택 구간에 다음을 기록한다.

`source_id, relative_path, kino_media_id, source_in_s, source_out_s, shot_at/evidence, location/confidence, scene, crowd, action, reaction, visual_quality, audio_role, text_space, recommended_role, reason, observed_range, consent_status`

`crowd`는 같은 축제 소스 내의 낮음/중간/높음 상대 비교와 근거(보이는 프레임 점유·대기열·이동 밀도)를 적는다. 정확한 인원 추정으로 바꾸지 않는다. 멀리 찍힌 정적인 인파보다 가까운 즐거운 반응이 편집에 더 적합할 수 있다.

## 셀렉트 판단

- 인파가 보이는 전경, 사람이 움직이는 동선, 진짜 반응, 손/면/국물/김의 동작, 장소를 알아볼 수 있는 표식.
- 수직 화면으로 잘랐을 때 이야기의 핵심과 자막 여백을 함께 유지할 수 있는지.
- 초점·노출·흔들림·모션·가림·끊긴 발언. 기술적으로 깨끗해도 내용 중복이면 후순위.
- 동의가 필요한 근접 방문객/아이들/인터뷰는 현장 확인 상태를 전달받는다. 대본에 없는 민감한 속성을 인물 외형에서 추론하지 않는다.
- ‘훅 후보 3개’, ‘증거 장면’, ‘음식 디테일’, ‘반응’, ‘전환/마무리’로 역할을 표시한다. 모든 점수를 억지로 하나의 숫자로 합쳐 순위를 확정하지 않는다.

새 파일이 들어오면 기존 relative path+size+mtime 인덱스로 변화를 먼저 찾고 중요 파일은 해시로 확인한다. 기존 분석·사람이 고른 구간·동의 상태를 덮어쓰지 않고 합친다. 스크립트의 새 인벤토리와 사람이 보완한 분석을 구분해 보존한다.
