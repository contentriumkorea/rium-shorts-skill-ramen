# 편집기 연결·초벌 실행·인계

이 스킬은 특정 편집기의 자동화 드라이버를 포함하지 않는다. 사용자가 사용하는 편집기와 현재 제공되는 연결에서 가능한 작업을 확인해 실행한다. Premiere Pro, DaVinci Resolve, Final Cut Pro, CapCut, After Effects 같은 제품 이름은 환경의 예시이며, 이 패키지가 모두에서 자동 편집·변환을 검증했다는 뜻이 아니다.

## 1. 편집기를 파악하고 실행 범위 정하기

1. 대화의 선택, 편별 인덱스, 프로젝트 안내, 실제 프로젝트 파일과 연결 앱을 확인한다. 확장자만으로 버전이나 자동화 가능 여부를 확정하지 않는다.
2. 편집기가 정해져 있으면 다시 묻지 않는다. 정보가 없거나 자료가 충돌할 때만 사용하는 편집기를 한 번 확인한다. 기다리는 동안 소스 인벤토리·하이라이트·대본·컷표를 준비한다.
3. 해당 편집기의 사용 가능한 플러그인·MCP·공식 스크립팅·CLI와 실제 버전의 가이드를 확인한다. 도구 이름·API 인자·ID·지원 포맷을 만들어 쓰지 않는다. 사용자 승인 없이 편집기를 바꾸거나 새 편집기·플러그인을 설치하지 않는다.
4. 지원 기능을 읽기, 클립 편집, 자막/그래픽, 음원 트랙, 저장, 내보내기로 나눠 확인한다. 연결됐다는 이유로 전 기능이 되는 것으로 표시하지 않는다. 대상 프로젝트·시퀀스와 수정 권한을 확인한다.

| 실제 가능한 범위 | 수행과 보고 |
|---|---|
| 네이티브 읽기·편집·저장 지원 | 대상 시퀀스를 편집하고 저장 상태를 재조회한다. 가능하면 미리보기·렌더도 확인한다. |
| 일부 기능만 지원 | 지원되는 부분을 실행하고 남은 레이어·출력 단계의 인계 자료를 만든다. 앱에 실제 적용된 범위를 구분한다. |
| 직접 편집 연결은 없지만 지원 교환 포맷 확인 | 해당 포맷의 자료를 준비한다. 임포트·재연결·타이밍·손실 확인 전에는 네이티브 편집 완료가 아니다. |
| 연결·지원 포맷 미확인 또는 부재 | 편집기 중립 컷표·자막·믹스 지시·자산 매핑·검수 계획을 저장한다. 네이티브 프로젝트/시퀀스 미작성과 렌더 미실행을 명시한다. |

## 2. 원본·시간·편집 구조

- 기존 프로젝트·시퀀스와 미디어 연결을 먼저 읽고 필요한 수정 전 백업/버전을 보존한다. 한 편 수정에 새 프로젝트를 만들거나 원본 소스를 덮어쓰지 않는다.
- 타임라인 크기·프레임률은 소스와 납품 조건으로 정하고 기존값을 유지한다. 낮은 해상도로 검수할 때 편집 좌표계 변경과 출력 배율 변경을 구분한다.
- source in/out과 timeline in/out을 따로 기록한다. 초·프레임·타임코드를 혼용하지 않고 API가 요구하는 단위와 fps 기준을 확인한다. 소스 fps와 시퀀스 fps는 다를 수 있으며 변속·VFR·드롭프레임은 해당 편집기의 실제 해석과 대조한다. 끝 프레임의 포함/제외 규칙도 확인한다.
- 영상 컷·제목·자막·BGM·SFX·VO는 가능하면 독립 클립/트랙/레이어로 유지한다. 편집 가능한 원본 대신 전체 영상이나 자막을 먼저 한 파일로 굽지 않는다. 중첩 시퀀스·컴포지션이 필요하면 실제 위치와 참조를 기록한다.
- 클립/레이어 ID는 실제 응답값을 사용한다. 구조 변경 뒤에는 재조회하고, ID가 없는 환경은 시퀀스·트랙·클립명·구간으로 대상을 교차 확인한다.
- 원본에 박힌 글자와 새 제목·요점 문구·전사 자막을 구분한다. 전사/생성 자막의 단일 기준 파일·트랙을 기록하고 중복 편집본을 만들지 않는다. 위치·폰트·효과는 장면과 편의 선택이며 전 편 고정값이 아니다.

## 3. 직접 편집할 수 없을 때의 자료

필요한 자료만 기존 승인된 편별 폴더에 만든다. 컷표에는 source ID/path, source in/out, timeline in/out, 시퀀스 fps, 역할, 크롭·속도, 화면 문구, 오디오 역할을 담는다. 자막에는 문구·시작/끝·배치 이유·가림 예외를, 믹스 지시에는 트랙별 파일·사용 구간·음량·페이드·발화 중 조정을 기록한다. 준비한 대본과 자산의 실제 존재를 확인한다.

SRT/VTT는 문구·시간 전달에 쓸 수 있지만 정확한 폰트·위치·스타일 재현을 보장하지 않는다. XML/AAF/EDL/OTIO 등은 대상 편집기의 현재 임포트 지원을 확인한 경우에만 선택한다. 확장자만 붙인 가짜 프로젝트를 만들지 않는다. 교환 과정에서 그래픽·효과·변속·믹스가 손실될 수 있으므로 미적용 항목을 함께 적는다.

교환 파일 생성은 임포트 성공이 아니다. 대상 편집기에서 열림·미디어 재연결·총 길이·컷 경계·자막·음원 트랙을 확인해야 해당 단계가 완료다. 직접 적용할 수 없으면 편집자가 수행할 남은 단계와 확인할 결과를 짧게 전달한다.

## 4. 실제 화면·저장·출력 검수

편집기 화면 또는 출력 표본에서 첫 2초 훅·최장 문구·움직이는 얼굴/음식/손·상단 주제·마지막 컷을 확인한다. [자막 조합·재검수](caption-layout-review.md)에 따라 이동·축약·노출 시간 변경·생략을 적용하고 이웃 컷과 다시 비교한다. 스크린샷 한 장이나 저장 성공만으로 전체 재생·청취·렌더를 통과시키지 않는다.

실제 프로젝트 경로, 시퀀스/컴포지션 식별자, 저장 시각·버전, 소스 연결과 필요한 앱/폰트/플러그인을 [편별 인덱스](episode-management.md)에 남긴다. 자동저장·캐시 존재를 정상 저장이나 복구 가능성의 증거로 삼지 않는다. 출력이 요청되면 크기·fps·길이·누락/검은 프레임·자막·음성을 검사하고 미검수 범위를 명시한다.

느린 렌더는 현재 코덱·해상도·fps·품질·실제 프레임 수·소요 시간을 기록한 뒤 같은 짧은 구간에서 지원 옵션을 비교한다. GPU 프로세스나 VRAM 점유만으로 하드웨어 인코딩을 사용한다고 판단하지 않는다. 렌더 중 해당 프로세스의 인코딩·디코딩·화면 합성 사용량과 로그를 대조한다. 다른 인코더 속도를 해당 편집기의 속도로 보고하지 않는다.

## 5. 연결 제한과 클라우드

도구별 오류·실행 여부·재시도 가능 여부를 구분한다. 일부 조회의 한도 오류를 모든 편집/렌더 불가로 일반화하지 않는다. 시도하지 않은 작업은 미시도로 기록한다. 명시적으로 허용되는 조회는 해당 범위에서 사용하되, 거절된 작업을 다른 도구·API·계정으로 우회하지 않는다.

로컬 파일을 사용하는 편집기라도 가져오기·분석·저장에 클라우드를 쓸 수 있다. 자동 업로드·분석·공유를 시작하지 말고 실제 전송 범위와 사용자의 허용 범위를 먼저 확인한다. 클라우드 중단 요청 시 업로드·분석·공유와 동기화를 수반하는 프로젝트 변경을 시작하지 않는다. 공식 설정에서 실제로 꺼졌는지 확인하기 전에는 오프라인 모드라고 보고하지 않는다. 기존 서버 파일 삭제·계정 전환·앱 네트워크 차단으로 임의 대체하지 않는다.
