# 프로젝트 연결과 재개

사용자가 지정한 실제 프로젝트 폴더나 현재 작업 디렉터리에서 시작한다. 기존 `README.md`, `codex/프로젝트 안내.md` 또는 편별 인덱스가 있으면 먼저 읽고 실제 파일과 대조한다. 특정 직원의 드라이브·계정·행사 문서·Kino ID를 기본값으로 사용하지 않는다.

촬영본·레퍼런스·준비 BGM의 위치와 기존 편 번호를 확인한다. 기존 구조가 `Footage`, `Sequence`, `Export`, `etc`를 사용하면 유지하고, 다른 구조라면 그 프로젝트 기준을 따른다. 없는 경로를 임의로 만들거나 기존 Kino 마운트를 옮기지 않는다. 일정·장소·납품 조건은 현재 프로젝트 문서에서 확인한다.

이 패키지의 [8편 분석](reference-analysis.md)은 제작 당시 모은 레퍼런스에 대한 사례 연구다. 원본 영상·음원·내부 운영 문서·Kino 프로젝트는 배포에 포함하지 않는다. 번호 01~08은 사례 식별자이며 새 사용자의 촬영본 번호가 아니다. 사례의 분석을 일반 편집 원리로 활용하고, 실제 소스 선정·문장·배치·음악은 사용자가 제공한 자산을 보고 결정한다.

2026-11-05 실제 Kino 30초 내부 시험에서 자막 배치·가림 수정과 렌더를 확인했다. [테스트 검증](kino-test-validation.md)의 수행 범위와 미검증 항목을 구분한다. 사례의 내부 프로젝트를 현재 본편으로 자동 편입하지 않는다.

호출 예:

```
$rium-shorts-skill-ramen
촬영본은 [폴더]. 인파와 먹거리 중심 30초.
두 방향을 추천해주고 내가 고르면 Kino에서 초벌 만들어줘.
```

Claude에서는 `Rium Shorts Skill - ramen 스킬로 ...`처럼 요청하거나 해당 환경의 스킬 선택 방식을 사용한다. Kino 편집 단계에는 Kino MCP 연결과 해당 작업 권한이 필요하며, 음성 생성 단계에는 실제 사용할 서비스의 연결도 확인한다.
