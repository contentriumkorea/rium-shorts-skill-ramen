# 실제 편집 시험과 검증 범위

## 과거 시험의 도구와 현재 적용 범위

2026-11-05 레퍼런스 01·07을 사용한 30초 내부 시험은 **당시 Kino에서 수행한 사례**다. 실제 프로젝트·검수 기록은 제작자의 비공개 작업 기록에 별도 보관하며 공개 패키지에는 포함하지 않는다. 본편 촬영본이나 공개용 축제 홍보물이 아니며, 이 사례가 다른 편집기의 자동 조작까지 검증했다는 뜻은 아니다.

현재 스킬은 편집자가 선택한 도구를 사용한다. 이 과거 사례 때문에 Kino 설치·계정·MCP 연결을 요구하거나 사용자가 쓰지 않겠다고 한 도구로 작업을 넘기지 않는다. 현재 편집기에서 가능한 연결·자막·타임라인·내보내기는 [편집기 실행](editor-workflow.md)에 따라 별도로 확인한다. 과거 사례의 좌표·폰트·구현 방식을 다른 편의 고정 템플릿으로 적용하지 않는다.

## 실제 수행한 편집과 가림 수정

- 로컬 MP4 두 개를 별도 1080×1920·30fps 프로젝트에 가져와 8개 구간, 900프레임, 합계 30초로 편집했다. 독립 영상·요점 자막·오디오 항목을 유지했다.
- 레퍼런스 01에서 인파·백팩·조리·라면·시식, 07에서 김밥 장면을 사용했다. 서로 다른 행사 자료를 금년 본편 촬영으로 소개하지 않았다.
- 07의 원본 혼합 오디오 0~30초를 독립 트랙으로 놓고 음량·시작·끝 페이드를 조정했다. 분리된 BGM이나 새로 확보한 본편용 음원이 아니며, 다른 영상 원음은 해당 내부 몽타주에서만 음소거했다.
- 중앙 새 자막과 상단 고정 제목을 비교해 음식·입·그릇을 가리는 것을 확인했다. 음식·김밥·마지막 한 입에서는 새 문구를 생략했고, 상단 고정 제목도 껐다. 원본에 이미 합성된 자막은 보존했다.
- 시식 문구를 상단으로 옮긴 첫 수정에서는 고개를 드는 순간 눈과 겹쳤다. ‘맛은?’으로 줄여 좌측 여백에 놓고 문구가 보이는 구간의 움직임을 다시 확인했다. 하단 이동이 모든 가림의 해답은 아니다.
- 백팩 요점 문구가 원본 내부의 다음 조리기 장면까지 남아 노출 종료를 6.8초로 앞당겼다. 전체 영상 길이는 유지했다.
- 조리 문구를 위 여백으로 옮기고 처음에는 11~14초에 표시했지만, 전체 출력의 13.9초에서 새로 등장한 요리사의 눈과 겹쳤다. 원본의 해당 범위를 다시 확인하고 최종 노출을 11~13초로 줄였다. 편집기 표본 검수 뒤에도 출력 검수를 생략하지 않아야 한다.

## 출력과 확인된 결과

Kino에서 30초·900프레임·1080×1920·30fps H.264/AAC 전체 파일을 출력하고 전체 디코딩을 확인했다. 그 PC의 해당 렌더는 약 15분 15초가 걸렸다. 특정 도구·PC·소스의 관찰값이며 다른 도구나 작업 속도로 일반화하지 않는다.

전체 출력에서 발견한 마지막 가림을 수정한 뒤 13~14초 30프레임을 Kino에서 다시 출력하고, FFmpeg로 기존 전체 렌더의 해당 프레임을 교체·결합했다. 최종 30초·900프레임, 전체 디코딩, 출력 표본과 수정 구간을 확인했으며 원래 AAC 오디오 payload가 그대로임을 해시로 대조했다. 이 마지막 구간 결합을 전체 영상을 다른 편집기로 편집·검증한 것으로 표현하지 않는다.

구간 출력 결합은 이 시험의 지원 작업이었다. 모든 편의 필수 방식이 아니다. 이를 사용하려면 변경 범위 밖의 소스·미디어·타이밍·오디오가 동일하고 정확한 프레임 수·경계·음성 보존을 확인해야 한다. 변경 범위를 특정할 수 없거나 전역 변경이면 전체 출력을 다시 검증한다. 초기 비교본의 불필요한 중복 전체 렌더는 취소했고, 가림 증거용 한 프레임 내보내기는 별도로 완료했다.

## 도구 제한·GPU·클라우드에서 확인하지 못한 것

당시 마지막 구간 출력 이후 일부 Kino 가이드·문서·프로젝트 상태 조회가 주간 MCP 호출 한도로 거절됐다. 이후 설정 목록 조회와 설정 화면 열기는 성공했다. 따라서 일부 요청의 거절을 모든 편집·렌더 불가나 유료 전환 필수로 일반화할 수 없다. 추가 요청된 2초 GPU 시험은 렌더 시작 명령 자체를 호출하지 않아 그 명령의 실행 가능 여부도 확인되지 않았다. 현재 도구에서도 성공·거절·미시도 상태를 각각 기록하고 이미 거절된 작업을 다른 경로나 계정으로 우회하지 않는다.

GPU 프로세스와 GPU 메모리 사용은 관찰했지만 렌더 중 하드웨어 인코딩 사용 여부는 측정하지 않았다. 720p·중간 품질은 비교 후보였으며 속도 개선이 검증된 설정이 아니다. 선택한 편집기의 실제 출력 옵션과 짧은 동일 구간의 소요 시간·GPU 인코딩 사용량을 확인하기 전에는 최적화 완료라고 보고하지 않는다.

당시 전체 클라우드 OFF 설정은 확인하지 못했고 실제로 끄지도 못했다. 원본 업로드를 따로 요청하지 않았다는 사실이 프록시·분석·프로젝트 동기화까지 꺼졌다는 뜻은 아니다. 이 스킬은 현재 선택한 편집기의 자동 업로드나 동기화를 일괄 해제하는 기능이 없으며, 로컬 파일 편집이 항상 오프라인으로 처리된다고 보장하지 않는다. 사용자가 클라우드 사용을 원하지 않으면 실제 설정과 데이터 이동 경로를 확인하고, 확인되지 않은 업로드·분석·동기화를 임의로 진행하지 않는다.

직접 청취, 실제 휴대전화 Instagram UI, 독립 자동 얼굴·음식 가림 검출, 자동 전사 자막 생성, ElevenLabs 음성 생성, 다른 PC의 미디어 재연결은 이 시험으로 검증하지 않았다. 에이전트가 실제 프레임을 보고 가림을 판단·수정하는 흐름을 시험했으며 원본 자막의 가림까지 제거했다고 주장하지 않는다. 최종 가림은 소스·출력에서 수정했지만 해당 편집기 검수 주석을 다시 해결 처리하는 동작은 완료하지 못했다.

레퍼런스·혼합 음원은 사용자가 명시한 내부 시험 범위에서만 사용했다. 사례 제공이 원본 매체의 재사용 권리나 공개·납품 승인을 제공하지 않는다. 실제 본편은 사용자의 촬영본과 이용 범위를 확인한 준비 BGM을 우선 사용한다.
