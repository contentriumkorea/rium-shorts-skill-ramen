# 사용·저작권 안내

제작·배포: Contentrium · 콘텐츠리움.

이 저장소에는 별도의 오픈소스 라이선스를 지정하지 않았다. 라이선스 배지나 설명에서 MIT 등 지정하지 않은 조건을 표시하지 않는다. 별도 배포·사용 조건은 제작자에게 확인한다.

레퍼런스 분석은 편집 원리와 검수 사례를 설명하기 위한 자료다. 원본 영상·사진·음악·긴 전사·내부 제작 문서는 배포에 포함하지 않는다. 분석 자료 제공을 원본 매체의 재사용 허가로 취급하지 않는다. 실제 제작에는 사용 가능한 촬영본·음원·폰트를 준비한다.

`assets/point-effects/`의 불꽃·반짝임·충격 팡·번개·하트·김은 이 프로젝트를 위해 새로 생성·가공한 그래픽 에셋이다. 레퍼런스의 픽셀·원본 타이포·음원을 복제하지 않았다. 미리보기 문구는 실제 폰트로 렌더했으며 폰트 파일은 동봉하지 않는다. 이미지 도구에서 모델 버전은 표시되지 않았으므로 특정 출시 모델로 제작했다고 주장하지 않는다.

README 커버와 기능도식은 이 스킬을 설명하기 위해 만든 SVG다. 실제 편집기 화면이나 실제 촬영 결과물로 표시하지 않는다. 편집기·서비스 이름과 상표는 각 소유자에게 속하며 공식 제휴를 의미하지 않는다.
