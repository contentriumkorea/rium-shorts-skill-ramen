# Instagram UI와 겹치지 않는 배치

## 근거와 적용 범위

2026-11-05 Meta 공식 [스토리·릴스 광고의 텍스트 오버레이 및 표시 영역](https://www.facebook.com/business/help/980593475366490)을 Aside로 확인했다. 9:16 광고에서 가장자리의 주요 텍스트/로고를 피하고 Ads Manager의 표시 영역 오버레이로 확인하도록 안내한다. 기기에 따라 확대·크롭·레터박스가 달라지며, 고지 사항이 있는 릴스 광고는 하단 40%를 비워 두라는 별도 권고도 있다.

이는 **광고 지침**이다. 일반 Instagram 게시물·Reels·피드·프로필 미리보기의 모든 UI에 통하는 고정 픽셀 규격으로 인용하지 않는다. 우측 좋아요/댓글/공유, 하단 계정 ID/설명/음악, 상단 뒤로가기/메뉴는 화면과 앱 상태에 따라 바뀐다. 확장된 설명/댓글 패널이 가리는 모든 상태를 완전히 피할 수는 없다.

## 프로젝트의 임시 검수 영역

실제 목표 화면 확인 전 초벌에 쓰는 **보수적인 내부 가이드**다. 아래 수치는 Meta가 보장한 규격이 아니다. 폰트·자막 정렬·위치를 강제하는 틀이 아니라 중요 문구의 바깥 경계를 검사하는 출발점이다.

| 영역 | 1080×1920 임시 범위 | 비율 |
|---|---|---|
| 상단 UI 주의 | y < 288 | 상단 15% |
| 하단 계정/설명/음악 주의 | y > 1248 | 하단 35% |
| 왼쪽 여유 | x < 86 | 약 8% |
| 오른쪽 버튼 열 주의 | x > 886 | 오른쪽 약 18% |
| 중요한 글·로고의 시작 검사 영역 | x=86~886, y=288~1248 | x .08~.82, y .15~.65 |

피사체와 배경은 화면 전체를 사용한다. 핵심 자막/브랜드/설명만 먼저 내부에 배치한다. 상단 고정 주제도 y=0에 붙이지 말고 내부의 상단 부분에 둘 수 있다. 중앙/하중앙 자막은 장면의 빈 공간에 두되 이 검수 영역, 실제 UI와 피사체를 함께 본다. 가독성 때문에 범위를 조정할 수 있지만 실제 표시 화면에서 확인해야 한다.

`assets/safe-area-preview.svg`는 검수용 참고 그림이다. Kino에서 임포트해 보조 레이어로 쓴 경우 최종 렌더에서는 반드시 제외한다. 렌더 소스에 기본 켜진 오버레이를 남기지 않는다. 1080×1920 외 형식은 비율을 기준으로 계산하고 피드 크롭은 별도 검사한다.

## 실제 검수 절차

1. 목표가 일반 Reels인지 광고인지 확인한다. 기존 요청이 인스타그램이면 우선 9:16 Reels 초벌로 가정하고 게시 경로를 기록한다.
2. 가능한 현재 모바일 Instagram 화면/사용자가 제공한 미리보기 또는 Ads Manager safe-zone overlay로 UI 경계를 확인한다. 데스크톱 Instagram 릴스 화면을 모바일 UI와 동일하다고 하지 않는다. 게시가 승인되지 않은 작업을 검수하려고 업로드하지 않는다.
3. 0초, 훅 완성 시점(2초 이내), 가장 긴 문장, 고정 주제+본문 동시 노출, 음식/얼굴 클로즈업, 마지막 프레임을 비교한다. 글자 바운딩 박스 전체가 범위 안에 있는지 확인한다.
4. 360×640 정도 휴대폰 크기 미리보기에서 자막을 실제로 읽어 본다. 한 화면의 중요 문구가 너무 많으면 줄인다. 음식·입·눈·손의 동작을 가리면 위치 또는 문구를 바꾼다.
5. 실제 앱 미리보기가 없으면 `내부 가이드 검사 통과 / Instagram 실기기 미검증`으로 남긴다. “완벽한 안전영역”이라고 보증하지 않는다.
