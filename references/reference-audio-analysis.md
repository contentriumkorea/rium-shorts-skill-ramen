# 레퍼런스 8편: 실제 오디오 분석

분석일 2026-11-05. 입력은 프로젝트 `etc/영상 레퍼런스/` 번호 01~08의 **실제 MP4 혼합 오디오**다. 원본 파일·음량은 수정하지 않았다. 설치되어 있던 모델/라이브러리만 사용했고 외부 업로드·새 모델 다운로드·비용 발생은 없었다.

## 분석 방법과 해석 경계

- AST(AudioSet 527 클래스): 16kHz 모노, 10초 창/5초 이동 및 마지막 창으로 전편 62개 창. 05·08 효과 후보만 4초 창으로 보완. sigmoid 점수는 존재 확률이나 소리 볼륨 비율이 아니다.
- CLAP: 48kHz 모노, 5초 단위 전체 커버리지+중앙/끝 창 87개. 균형 잡힌 32개 설명과 코사인 유사도 비교. 2초 미만 꼬리 창은 집계에서 제외. 가장 유사한 문구가 실제 소리의 정답이라는 뜻은 아니다.
- FFmpeg loudnorm의 **input** integrated LUFS/true peak 측정. 이는 BGM 단독이 아니라 음성·음악·효과음이 섞인 전체 파일이다.
- librosa onset/주기성 및 tempo 추정. 말의 리듬·타격음·컷 변화와 음악 박자를 혼동할 수 있고 절반/두 배 해석이 가능하다.
- 이전 로컬 ASR/화면 분석과 대조했다. 이 호스트는 오디오 입력을 직접 청취하는 기능을 지원하지 않으므로 **파형 기반 모델 분석 완료 / 청취 검수 미실시**다. 곡명·원곡자·정확 악기/장르·SFX 이름·TTS 여부·덕킹·스테레오 배치·비트-컷 동기는 확정하지 않는다.

## 편별 결과 → 준비할 음악 선택 방향

아래 선택 방향은 새 편집을 위한 제안이다. 원래 레퍼런스의 믹싱 비법을 정확히 재현했다는 주장이 아니다.

| 번호 | 모델/전사에서 함께 드러난 경향 | 준비한 BGM 파일에서 먼저 검토할 성격 | 편집에 연결 |
|---|---|---|---|
| 01 방문 후기 | 말소리+음악 공존. AST Speech 평균 .810/Music .845, CLAP도 speech+music 우세 | 목소리를 가리지 않고 일정한 흐름을 받치는 구간 | 동선/체험 설명이 먼저. BGM 보컬과 발화가 경쟁하면 다른 구간/무보컬 선택 |
| 02 축제 소개 | 음악/보컬 음악 중심. AST Music .672, CLAP singing_music가 전 창 우세 | 첫 장면부터 리듬을 쓸 수 있는 짧은 구간. 보컬 곡도 후보 | 초반 제목 이후 영상 몽타주. 노랫말과 긴 정보 자막이 경쟁하지 않는지 검수 |
| 03 야시장 | AST Speech .885/Music .832. CLAP은 말+음악/보컬 음악 경합, ASR은 설명형 | 짧은 설명 위에 깔아도 복잡하지 않은 구간 | 첫 2초 의미 전달 우선. 큰 비트에 맞추려고 훅 문장을 늦추지 않기 |
| 04 비 오는 날 방문기 | 말소리 중심. AST Music 평균 .014로 낮음. BGM 없음의 증거는 아님 | 여정 설명에 여백을 주는 단순한 배경, 또는 필요한 구간만 음악 | 시간/장소 챕터와 경험을 따라감. 빗속 화면만 보고 빗소리를 들었다고 하지 않기 |
| 05 대박 난 이유 | 연속 설명 중심, 짧은 충격성/팝 계열 효과 후보 | 음악으로 밀어붙이기보다 말이 잘 들리는 저밀도 구간 | 이유·반전의 몇 지점에만 짧은 소리 포인트를 검토. 모든 문장에 효과음 금지 |
| 06 첫날 인파 | 음악 중심 및 보컬 후보. 약 92BPM/184BPM 해석의 강한 주기성 | 리듬 자체가 장면을 이어주는 구간 | 긴 현장 컷도 유지 가능. 추정 비트가 있다고 컷을 모두 짧게 자르지 않기 |
| 07 솔직 후기 | 전편 음악 중심. AST Music .933/Speech .002, CLAP/ASR도 보컬 음악 쪽 | 후기 자막을 읽는 데 방해되지 않는 리듬·보컬 밀도 | 화면 후기 문구를 그대로 VO로 추가하지 않기. 자막과 노래의 역할 분리 |
| 08 축제 근황 | 말소리 중심. AST Music .001~.327로 창별 변화, 끝에 효과 후보 | 설명의 반전/마무리를 살릴 여백 있는 구간 | 후반 강조 후보만 검토. 음악 진입/이탈 시점을 모델 점수로 단정하지 않기 |

04·05·08의 낮은 음악 점수는 작은 BGM을 모델이 놓쳤을 가능성이 있다. 02·06·07의 가창 후보도 정확한 가수/성별/곡명을 알려주지 않는다. CLAP의 hiphop/comedy/laughter 후보가 설명 음성에서도 높게 나왔으므로 장르·웃음 효과음 사실로 채택하지 않았다.

## 효과음: 우선 확인할 구간

이 표는 **청취할 범위를 줄인 후보 목록**이다. 실제 효과 발생 프레임, 소리의 출처, 개수, 사용 음량을 확정한 cue sheet가 아니다. 4초 창의 패딩과 음성 자음의 영향이 있어 짧은 창 점수와 10초 창 점수를 직접 비교하지 않는다.

| 영상/우선 구간 | 근거 | 새 편집에서 검토할 기능 |
|---|---|---|
| 05 · 32.5~33.5초 주변 | 30~34초 및 32~36초에 AST Plop .848/.807. 독립 flux 피크 32.676/33.186초 | 근거 한 항목을 찍어 주는 짧은 포인트 소리 후보 |
| 05 · 37.3~37.8초 주변 | 34~38초/36~40초에 짧은 충격성 라벨. flux 피크 37.546초. 정확 정체 불명 | 강조/반전의 구두점 역할 후보. 실제 총성 등으로 묘사하지 않음 |
| 05 · 45.7~46.2초 주변 | 42~46초/44~48초 Plop .185/.443. flux 피크 45.936/46.046초 | 다음 근거나 재후킹 앞뒤 포인트 후보 |
| 08 · 34~40초 | 34~38초/36~40초 Plop .100/.186. flux 피크는 34.446/38.366/38.856초로 분산. 10초 창의 Boing은 짧은 창에서 약해짐 | 끝의 짧은 강조 후보. 교집합인 36~38초만으로 좁히지 않으며 탄성 효과로 확정하지 않음 |
| 08 · 3~7초 | Ding .077로 약한 후보 | 선택적 추가 검토만. 해당 효과를 필수 요소로 추출하지 않음 |

flux 피크는 신호가 급격히 변한 지점이며 음성 자음·음악 비트에서도 생긴다. 위 시각은 청취 우선순위를 좁힌 결과일 뿐 효과음의 확정 cue가 아니다.

01·03·04·06·07에서는 이 분석으로 채택할 만한 특정 SFX 이름/정확 시점을 확인하지 못했다. 이는 효과음이 없다는 뜻이 아니다. 조리·인파·비가 보인다는 이유로 지글거림·군중음·빗소리를 임의 기입하지 않는다. 모델 효과 라벨과 실제 선택 음악의 타악기를 혼동하지 않는다.

## 스킬 실행에 반영

1. [준비된 음원 파일](prepared-music-library.md)에서 ‘음악 중심 몽타주’와 ‘설명 보조’ 후보를 구분해 곡/구간 2개를 추천한다. 부족하다고 자동 생성·다운로드하지 않는다.
2. 듣지 못한 후보는 자동 분석으로 표시한다. BPM/이벤트 결과만으로 “영상에 잘 어울린다”, “이 소리는 정확히 팝 효과다”라고 확정하지 않는다.
3. 실제 현장 발화/조리 소리가 좋다면 레퍼런스보다 현장음 비중을 높이는 안도 제안한다. 음악을 더 크게 넣는 것이 완성도가 높다는 의미가 아니다.
4. SFX는 실제 행동/정보 전환/반전의 소수 지점에서만 시험한다. 두 소리가 겹치면 역할이 더 분명한 하나를 남긴다. 의미 없는 효과음으로 모든 컷을 표시하지 않는다.
5. 청취 가능한 환경에서는 음성 마스킹, SFX 과장, 갑작스러운 레벨, 루프 접합, 끝 잔향을 확인해 `listened` 상태를 별도로 기록한다.

원시 모델 점수·창·측정·모델 분석 재현 스크립트는 제작자의 비공개 검증 기록에 별도 보관했다. 공개 패키지는 분석 요약과 일반 파일 인벤토리·오디오 신호 측정 도우미를 제공하며, 모델 가중치·원본 음원·내부 검증 자료·인증정보를 포함하지 않는다.
