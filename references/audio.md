# 음악·현장음·효과음·ElevenLabs

## 레퍼런스에서 확인된 범위

8편의 실제 오디오를 로컬 Whisper 전사, AST 음향 사건 분류, CLAP 음향-텍스트 비교, FFmpeg 음압 및 리듬 신호 측정으로 분석했다. 자세한 구간·근거·한계는 [실제 오디오 분석](reference-audio-analysis.md)을 읽는다. **파형 기반 자동 분석이며 직접 청취 검수는 아니다.**

02·06·07은 음악 중심 후보, 01·03은 말+음악이 함께 있는 후보, 04·05는 말 중심 후보, 08은 말 중심이되 일부 음악 추정이 달라지는 후보로 취급한다. 이것은 음악/음성의 정확한 볼륨 비율이나 믹서 트랙 분리 결과가 아니다. 특정 효과음·곡명·악기·실제 덕킹/비트 싱크는 확정하지 않았다. 낮은 음악 분류 점수도 ‘BGM 없음’의 증거가 아니다.

아래는 분석에서 얻은 **새 편집의 제안 기준**이다. 실제 청취 가능한 도구/사용자 확인이 있으면 `소스, 구간, 들린 소리, 역할, 믹스, 확신도`를 추가한다. 전사·진폭·모델 라벨만으로 특정 효과음을 들었다고 하지 않는다.

## 콘텐츠별 소리 방향

- 음식·조리: 국물/끓는 소리/그릇/젓가락/반응 등 실제 현장음이 가치가 있으면 잠깐 전면에 둔다. 실제 음원에 없는 소리를 ‘현장음’이라고 표시하지 않는다.
- 인파·축제 스케치: 음악이 리듬을 연결하고 중간에 현장 함성·웃음 등 확인한 소리를 살릴 수 있다. 음악만 큰 상태로 현장감이 묻히지 않는지 듣는다.
- 방문기·정보: VO 또는 현장 발화가 정보를 전달하고 BGM은 말의 틈을 잇는다. 자막+내레이션+고정 제목이 같은 내용을 세 번 반복하면 하나를 줄인다.
- 짧은 몽타주: 음성 없이 첫 훅+좋은 장면만으로 충분하면 TTS를 생성하지 않는다.

곡은 사용자가 사전 준비한 파일에서 먼저 고른다. [음원 라이브러리](prepared-music-library.md)를 읽고 실제 파일 경로·출처·사용 구간과, 선택한 편집기에 이미 가져온 파일인지 확인한다. 부족한 성격을 알리되 온라인 검색·구매·음악 생성으로 자동 넘어가지 않는다. 특정 아티스트·곡·장르를 기본값으로 고정하지 않는다. 2개 정도 후보에 ‘이 소리가 어떤 장면을 살리는지’ 이유를 붙여 큐레이션한다. 레퍼런스에서 음악을 추출해 납품본에 재사용하지 않는다. Instagram 앱 안에서 선택할 수 있는 음악을 외부 렌더에 사용할 권한과 동일시하지 않는다.

효과음은 정보가 전환되는 순간·실제 동작의 포인트에만 제안한다. 모든 컷에 whoosh, 모든 문장에 pop, 마지막에 무관한 riser를 자동 넣지 않는다. 강조가 필요한 순간이 없으면 SFX 없이 만든다. 피크 미터와 청취로 클리핑/갑작스러운 음량/과한 저역을 확인하고, 납품 규격이 없으면 임의 LUFS 수치를 플랫폼 의무 규격처럼 제시하지 않는다.

## ElevenLabs 흐름

1. 짧은 의도에서 톤을 제안한다: 친근한 동행, 간결한 정보, 현장감 있는 소개 등. 실제 사람/유명인의 목소리 복제를 기본으로 삼지 않는다. 기존 승인된 목소리가 있으면 재사용한다.
2. 방향과 대본이 정해지고 VO 생성이 요청/위임된 범위에서 실행한다. 문장과 읽는 호흡을 먼저 정리하고 매번 여러 전체 버전을 생성하지 않는다. 숫자·날짜·장소·제품명 발음을 점검한다.
3. 연결 ElevenLabs의 현재 `creative-studio` 또는 TTS 가이드를 읽고 `creative_list_voices`, `creative_generate_speech` 등 현재 스키마를 확인한다. 모델/voice_id/기본 생성 수는 라이브 도구 값으로 정한다. 후보 수·비용 기본값이 여러 개면 필요한 생성 수로 좁힌다. 연결이 없으면 설치·키 노출을 강요하지 않고 대본/편집은 진행, VO만 미완료로 남긴다.
4. 생성 시작 응답의 flow/session/node ID를 보존하고 완료까지 해당 작업만 추적한다. 타임아웃을 새 생성 요청으로 재시도하지 않는다. 파일을 받은 뒤 길이·음성 내용·발음·속도를 확인한다. 청취 불가라면 미청취 상태와 필요한 확인 단어를 알린다.
5. 완료된 음원 파일을 승인된 프로젝트 자산 경로에 저장하고 선택한 편집기의 가져오기 기능으로 연결한다. 음원 경로와 편집기에서 실제 확인한 항목 식별자를 기록하고 독립 VO 트랙 또는 레이어를 둔다. 확정 음원 길이와 실제 발화 타이밍에 맞춰 컷·자막을 조정한다. 글자 수로 단어별 자막 시각을 날조하지 않는다.
6. 음악은 발화 중 적절히 낮추고 문장 끝과 다음 컷에 자연스럽게 이어지는지 듣는다. 좋은 현장 발화가 있는데 TTS로 중복 설명하지 않는다. 선택한 편집기의 현재 가져오기·믹싱·내보내기 기능과 [편집기 실행](editor-workflow.md) 절차를 따른다. ElevenLabs 사용이 특정 영상 편집기를 필수로 만들지는 않는다.
