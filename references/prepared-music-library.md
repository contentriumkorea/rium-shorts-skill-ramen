# 사전 준비한 BGM 파일을 사용하는 방식

사용자는 음악을 미리 파일로 준비한다. **새 음악 검색/생성보다 지정된 음원 폴더를 우선 사용**한다. 폴더가 아직 없으면 필요한 성격을 추천해 두고 나중에 지정받는다. 사용자 홈/드라이브 전체를 음악 찾기로 훑지 않는다. 음악 생성·온라인 다운로드를 자동 대체 수단으로 실행하지 않는다.

## 라이브러리 만들기

기존 폴더와 원래 곡명을 보존한다. `scripts/inventory_media.py`로 duration, sample_rate, channels, 코덱·해시를 확인할 수 있다. 이는 음악 분위기 분석 도구가 아니다. 해당 출력과 별도 `music-catalog.json`을 연결한다. 새로운 승인 파일만 분석해 추가하고 이미 고른/거절한 곡 기록을 유지한다.

실제 음압·리듬 측정은 아래 도우미를 사용한다. `<skill-dir>`은 현재 읽는 SKILL.md의 폴더이고 출력 부모 폴더는 이미 있어야 한다. 기존 결과를 덮어쓰지 않으므로 새 파일명을 선택한다.

```text
python "<skill-dir>/scripts/inspect_audio.py" --source "<지정된 음원 파일 또는 폴더>" --output "<기존 분석 폴더>/audio-inspection-v001.json"
```

FFmpeg·ffprobe가 필요하다. 첫 오디오 스트림 전체의 LUFS-I/true peak/LRA를 측정하고, 이미 설치된 librosa가 있을 때만 최대 첫 300초의 템포를 추정한다. 오디오 스트림이 여럿이면 나머지는 분석되지 않았음을 확인한다. 템포는 말·타격음을 음악 박자로 오인하거나 절반/두 배로 나올 수 있다. 입력 변경·접근 오류·무음의 null 측정은 결과 상태를 확인하고 정상 수치처럼 사용하지 않는다. 도우미는 원본을 수정하거나 의존성을 설치하지 않으며, BGM/SFX 분리·곡명·분위기·직접 청취를 판정하지 않는다. 음악 카탈로그에는 측정 결과와 실제 청취/음향 모델 해석을 구분해 연결한다.

기록 항목:

- `track_id`, `relative_path`, `hash`, `title`, `source/license_status`, `editor_item_reference`(가져온 뒤 실제 확인한 식별자 또는 프로젝트 내 경로·항목 이름).
- `duration`, `vocal_presence`, `density`, `energy_curve`, `rhythm_feel`, `instrument_texture`, `speech_compatibility`, `ending_type`.
- `useful_ranges`: source in/out, 인트로/그루브/상승/브레이크/엔딩 역할, 확정 본편 길이에 필요한 음악 구간의 확보 여부, 잘라야 할 지점·잔향. 대본 없는 편의 45~90초와 대본에 맞춘 편별 길이를 기준으로 검토하며 음악 구간 길이를 영상 길이의 기본값으로 삼지 않는다.
- `tempo_estimate`는 숫자만 말고 추정 방법·half/double ambiguity·신뢰 한계를 적는다. BPM이 같아도 같은 곡의 느낌이 아니며 모든 컷을 비트마다 자르지 않는다.
- `evidence`: 실제 청취/사용자 확인/음향 모델 추정/신호 측정 중 무엇인지, 구간, 검토 시점. 메타데이터 곡명만으로 분위기를 확정하지 않는다.

권리 정보가 없는 트랙은 삭제하지 않고 상태를 표시한다. 내부 임시 초벌 선택과 공개/납품 사용 가능 여부를 구분한다. 이미 사용자가 이용 권한을 확인해 둔 음악에 매번 같은 확인을 반복하지 않는다.

## 초벌용 음악 큐레이션

촬영본의 에너지·인물 반응·컷 길이·정보량·VO 유무를 보고 **곡+구간** 2개 정도를 제안한다. ‘파일 A의 0:24부터는 도입이 길지 않고 일정한 리듬이 있어 인파 몽타주에 맞음’, ‘파일 B 0:10~0:40은 보컬이 없어 설명을 덮지 않음’처럼 실제 확인 근거를 쓴다. 아직 듣지 못했다면 이 예문을 사실처럼 사용하지 말고 후보로 표시한다.

이 구간 예시는 원음의 시작·끝이며 본편 전체 길이 지시가 아니다. 대본·장면으로 정한 편 길이에서 음악이 필요한 범위를 먼저 정하고, 부족하면 다른 적합 구간·곡 전환·검수한 음악 루프나 의도적인 현장음 구간을 비교한다. BGM을 끝까지 쓰려고 영상을 늘리거나 짧은 음악에 맞춰 대사를 자르지 않는다.

- 목소리 중심: 밀도/보컬 간섭이 적고 문장 사이를 자연스럽게 잇는 구간.
- 짧은 현장 스케치: 첫 장면부터 리듬을 쓸 수 있고 시작을 오래 기다리지 않는 구간.
- 음식/먹방: 실제 조리 소리를 살릴 여백, 불필요하게 웅장하거나 강한 전환음을 피할 수 있는 구간.
- 체험/가족/방문기: 감정·시간 흐름에 맞는 에너지, 긴장감을 억지로 만들지 않는 구간.

이 분류는 추천 기준이지 장르 강제 규칙이 아니다. 사용자가 선택한 취향과 편별 다양성을 유지한다. 이전 편과 같은 곡을 재사용할 때는 같은 구간 반복이 의도적인지 확인한다. 음원 수가 적으면 구간·믹스만 바꾼 것을 다른 곡처럼 소개하지 않는다.

## 선택한 편집기에서 편집·수정

선택 파일의 원본 경로와 편집 프로젝트의 기존 항목을 대조해 재사용하고, 아직 가져오지 않았다면 선택한 편집기의 가져오기 기능으로 연결한다. 해당 기능이 클라우드 업로드를 동반하는지 확인하고 사용자 범위를 따른다. 원래 트랙과 편집용 구간을 따로 기록한다. BGM·VO·현장음·SFX는 각각 수정 가능한 독립 트랙 또는 레이어로 두고 `source in/out`과 `timeline in/out`을 명확히 구분한다. 곡 전체를 미리 하나의 완성 믹스로 구워 놓지 않는다. 실제 저장과 재연결 확인은 [편집기 실행](editor-workflow.md)을 따른다.

문장 중 음악을 낮추고 중요한 현장 소리 앞뒤를 비우는 안을 실제 소리 기준으로 조정한다. 끝은 영상 끝에서 임의 절단하지 말고 프레이즈 종료·적절한 페이드·잔향을 검수한다. 루프가 필요하면 접합점을 실제로 확인한다. 음악 교체 시 자막·소스 순서가 불필요하게 바뀌지 않도록 하고 리듬과 엔딩만 다시 검수한다.

사전 파일 준비 팁: 가능하면 가사 없는 버전/보컬 버전, 짧은 컷다운/엔딩, 제공된 stems, 출처·이용 확인 자료를 함께 두면 빠르다. 원본 WAV 또는 고음질 압축 파일을 그대로 보관하고, 불필요한 재인코딩을 기본 작업으로 만들지 않는다. stem 파일이 없다고 자동 분리를 시작하지 않는다.
